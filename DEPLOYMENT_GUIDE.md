# Deployment Guide - Localhost vs Render

This guide explains how to configure the Finance Tracker application for different environments using the `BASE_URL` environment variable.

## Problem Solved

Previously, the application had hardcoded references that could cause routing issues when switching between localhost development and production deployment (Render). Now, all URLs are dynamically configured through environment variables.

## Environment Variable: BASE_URL

The `BASE_URL` variable tells the application what its public URL is. This is used for:
- **CSRF Protection**: Automatically configures trusted origins
- **OAuth Redirects**: Google OAuth callback URLs
- **Email Links**: Password reset, notifications
- **Absolute URL Generation**: Any feature requiring full URLs

## Configuration by Environment

###  Localhost Development

**In your `.env` file**:
```env
BASE_URL=http://localhost:8000
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
```

### 🐳 Docker Development

**In your `.env` file**:
```env
BASE_URL=http://localhost:8000
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
DB_HOST=db
```

### ☁️ Render Production

**Option 1: Via Render Dashboard**
1. Go to your service on Render
2. Navigate to "Environment" tab
3. Add/Update these variables:
   ```
   BASE_URL = https://your-app-name.onrender.com
   DEBUG = False
   ALLOWED_HOSTS = your-app-name.onrender.com
   ```

**Option 2: Via render.yaml** (Already configured)
```yaml
envVars:
  - key: BASE_URL
    value: https://your-app-name.onrender.com
  - key: ALLOWED_HOSTS
    value: your-app-name.onrender.com
  - key: DEBUG
    value: False
```

> **Note**: Replace `your-app-name` with your actual Render service name

## Complete Environment Reference

### Localhost `.env` Example
```env
# Application
SECRET_KEY=your-secret-key-here
DEBUG=True
BASE_URL=http://localhost:8000
ALLOWED_HOSTS=localhost,127.0.0.1
CSRF_TRUSTED_ORIGINS=http://localhost:8000,http://127.0.0.1:8000

# Database (local PostgreSQL)
DB_NAME=finance_tracker
DB_USER=postgres
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=5432

# Optional: AI Features
GEMINI_API_KEY=your-gemini-key
RESEND_API_KEY=your-resend-key
```

### Render Production Environment
```env
# Application
SECRET_KEY=<auto-generated>
DEBUG=False
BASE_URL=https://your-app-name.onrender.com
ALLOWED_HOSTS=your-app-name.onrender.com

# Database
DATABASE_URL=<auto-configured by Render>

# Optional: AI Features
GEMINI_API_KEY=your-gemini-key
RESEND_API_KEY=your-resend-key
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
```

## How It Works

The `BASE_URL` variable is integrated into Django settings:

```python
# In settings.py
BASE_URL = config('BASE_URL', default='http://localhost:8000')

# Automatically configures CSRF protection
default_csrf_origins = f"{BASE_URL},http://localhost:8000,http://127.0.0.1:8000"
CSRF_TRUSTED_ORIGINS = config('CSRF_TRUSTED_ORIGINS', default=default_csrf_origins, cast=Csv())

# Available for absolute URL generation
SITE_URL = BASE_URL
```

## Switching Between Environments

### From Localhost to Render

1. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "Update configuration"
   git push
   ```

2. **Update Render Environment Variables**:
   - Go to Render Dashboard → Your Service → Environment
   - Set `BASE_URL` to your Render URL
   - Render will auto-deploy

3. **Configure OAuth** (if using Google Sign-In):
   - Go to [Google Cloud Console](https://console.cloud.google.com)
   - Add `https://your-app-name.onrender.com/accounts/google/login/callback/` to authorized redirect URIs
   - Update `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` in Render

### From Render to Localhost

1. **Update `.env` file**:
   ```env
   BASE_URL=http://localhost:8000
   DEBUG=True
   ```

2. **Run locally**:
   ```bash
   python manage.py runserver
   # or with Docker
   docker-compose up
   ```

## Google OAuth Configuration

For Google Sign-In to work across environments:

### Localhost
- Authorized JavaScript origins: `http://localhost:8000`
- Authorized redirect URIs: `http://localhost:8000/accounts/google/login/callback/`

### Render Production
- Authorized JavaScript origins: `https://your-app-name.onrender.com`
- Authorized redirect URIs: `https://your-app-name.onrender.com/accounts/google/login/callback/`

## Troubleshooting

### CSRF Verification Failed

**Problem**: Forms submit but get CSRF errors

**Solution**:
1. Check `BASE_URL` matches your current URL
2. Verify `CSRF_TRUSTED_ORIGINS` includes your domain
3. For HTTPS, ensure it starts with `https://`

### OAuth Redirect Mismatch

**Problem**: Google OAuth fails with "redirect_uri_mismatch"

**Solution**:
1. Update Google Cloud Console with correct callback URL
2. Ensure `BASE_URL` matches your actual domain
3. Restart the application after changes

### Absolute URLs Incorrect

**Problem**: Links in emails point to wrong domain

**Solution**:
1. Verify `BASE_URL` is set correctly
2. Use `settings.SITE_URL` in code that generates absolute URLs
3. Restart application after environment changes

## Best Practices

1. **Never commit `.env`**: Keep it in `.gitignore`
2. **Use different keys**: Use unique `SECRET_KEY` for each environment
3. **HTTPS in production**: Always use `https://` in `BASE_URL` for Render
4. **Debug off in production**: Set `DEBUG=False` on Render
5. **Document your URLs**: Keep a note of your Render service name
